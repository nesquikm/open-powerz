# The rate tooltip over HID blames authentication

## Summary

In the browser edition a meter connected over HID gives basic readings only, so the rate picker is disabled.
Its tooltip said the rate was set on the meter because authentication was unavailable.
That is the wrong reason: HID carries no queue rates at all.
Now the tooltip says the rate is not available over HID, in the same words the PD capture refusal uses.

## Requirement

### Steps to reproduce
1. Hold the meter's bulk interface with another program and connect over HID in the web edition.
2. Hover the disabled rate picker.

### Expected
The tooltip says the rate is not available over HID because it gives basic readings only.

### Actual
The tooltip says "Rate set on the meter (measuring…) — authentication unavailable" (web HIL round 4, W10).

## Acceptance Criteria

- AC-09R2FK.1: Regression: for a session that gives basic readings only, the rate picker is disabled and its label is "Rate change is not available over HID: it gives basic readings only.", whatever the measured rate.
- AC-09R2FK.2: The PD capture refusal over HID and the rate label share one wording, built by the same helper.
- AC-09R2FK.3: A rate-locked session over WebUSB or the desktop app (authentication failed) keeps its "authentication unavailable" label, and a recording still locks the rate as before.
- AC-09R2FK.4: The top bar and the meter controls both pass the HID flag to the rate picker, so both tooltips use the HID label.

## Technical Design

### Root cause
The rate picker only knows the connection state; a HID session reports rate locked, which the picker explains as failed authentication.

### Fix
Give the picker the session's basic-readings flag and, when it is set, return the HID label. Export the HID wording helper from the web features module and use it in the driver's refusal too.

## Testing

Vitest on the rate picker for the HID, rate-locked and recording cases, and on the driver's PD refusal text. A source check that both callers pass the flag.

## Notes

Reported as a minor by the web HIL round 4 (W10).
