# The first rows of a session have no TEMP

## Summary

A browser export left TEMP empty in the first rows of a session, about 0.4 seconds.
The desktop app does the same.
Both take the temperature from a reading made after the first batch of samples.
The rule is now written down for both editions.
The browser also logs a debug line when a temperature reading fails or is empty.

## Requirement

### Steps to reproduce
1. Connect the meter over WebUSB in the web edition, let it stream, export the session.

### Expected
TEMP follows the same rule as the desktop, and the rule is written down.

### Actual
Rows 1 to 20 (0.38 s) have no TEMP; the reason is not visible (web parity HIL 4, P14).

## Acceptance Criteria

- AC-3B70S7.1: Regression: in the web session, samples that arrive before the first valid temperature reading carry no TEMP in the live batch, the record CSV and both exports, and samples after it carry it as before.
- AC-3B70S7.2: The desktop session keeps its behaviour: the records of the first queue poll, appended before the first snapshot, carry no TEMP; a test pins it.
- AC-3B70S7.3: While the web queue streams, a temperature snapshot that fails or reads no temperature logs one debug line saying which; the next line comes only when the outcome changes.
- AC-3B70S7.4: The user docs on exports say that rows before the first valid temperature reading have no TEMP, in both editions.

## Technical Design

### Root cause
Both editions take the temperature from an ADC snapshot read after the queue poll. The desktop stores records before the first snapshot; the web judges after it, so on the meter its first snapshot after a queue start most likely failed or read the invalid marker.

### Fix
No change to the rule; pin it in both editions, add the debug line in the web driver, and document it.

## Testing

Vitest for the web session and driver log; a Rust test in the desktop store or worker for the first poll.

## Notes

The desktop is the reference (brief). The HIL run should read the debug line after a connect.
