# open-powerz brand art, app icon and README banner

## Summary

The project gets its own look, built on the electron-surf mascot the user picked.
The art sources and a small generator live in the repository under the MIT licence.
It is original art with no fonts and no vendor marks.
The desktop app icon becomes the mascot's head, with a simpler small-size drawing that reads at 16 pixels.
The repository README opens with a banner, and the social preview and favicon are kept for later use.

## Requirement

The repository holds the electron-surf brand kit (SVG sources, rendered PNGs and the generator that makes them), the desktop app icon set is regenerated from it with the Tauri icon tool, and the README starts with the brand banner.

## Acceptance Criteria

- AC-492Z4N.1: The repository holds a brand folder with the SVG sources of the meter logo, the meter logo with wordmark, the app icon, the README banner, the social preview and the favicon, and their PNG renders: both meter logos at 200×200 with alpha 0 or 255 only, the app icon at 1024 px, the banner at 1280×400, the social preview at 1280×640 and the favicon at 16 and 32 px.
- AC-492Z4N.2: The brand folder's README says the art is original art for this project under the MIT licence, that the lettering is drawn from stroke glyphs with no font, that it carries no ChargerLAB or POWER-Z marks, lists each asset, and says how to re-render it.
- AC-492Z4N.3: The generator in the brand folder needs only Python's standard library, Pillow, rsvg-convert and, for its meter-logo preview check, a debug build of the powerz CLI, rewrites the generated SVGs and every PNG in the brand folder, and writes on-meter mocks and preview checks only to an output folder given on the command line, never into the repository.
- AC-492Z4N.4: The desktop app's icon source is the brand app icon and its small-size source is the brand favicon, byte for byte, and every platform icon file (icns, ico, Linux PNGs, Square logos) is regenerated from them with the existing icon script, which runs the Tauri icon tool; the existing size and transparent-margin checks still pass.
- AC-492Z4N.5: The repository README's first line is the banner image, by a relative path into the brand folder, with alt text naming open-powerz and the meter.
- AC-492Z4N.6: The social preview is kept in the brand folder and the brand README says it is set by hand in the GitHub repository settings; the favicon is kept there for the web edition and is not wired into any page yet.

## Technical Design

Brand folder at the repository root holding the SVGs, PNGs, a README and a tools folder with the two generator scripts, adapted from the research kit: output paths point at the brand folder, mocks and previews at a required output folder, and the meter-logo SVG is a checked-in source rather than a copy. The desktop icon SVGs are replaced and the icon script is run unchanged. The README gets a banner line above the title.

## Testing

A Vitest file beside the icon tests reads the brand PNG headers for sizes, scans both meter logos for alpha values other than 0 and 255, compares the two desktop icon sources with the brand files, checks the README's first line and the brand README's licence wording. The existing icon tests cover the regenerated platform files.
