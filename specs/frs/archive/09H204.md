# The File tab has no overview strip

## Summary

The live chart has a small timeline strip under it: the whole session, with the part on screen marked.
The File tab has no such strip, so a zoomed recording loses its place in the whole file.
Now the File tab shows the strip too, in the desktop app and the web edition.
Dragging or clicking it moves the zoom, the same way it does under the live chart.
The README screenshot shows it under the zoomed chart.

## Requirement

Show the overview strip under the File tab's chart: the whole file's envelope, with a window over the range on screen. Moving the window, or clicking the strip, shows that range in the chart.

## Acceptance Criteria

- AC-09H204.1: With a recording open, the File tab shows the overview strip under its chart, painted from the whole file, in both the desktop app and the web edition.
- AC-09H204.2: The strip's window covers the range the chart shows: the whole strip when the file is not zoomed, and only the zoomed part after a zoom.
- AC-09H204.3: Dragging the window, or clicking or using the keyboard on the strip, shows the chosen range in the File tab's chart, and the stats follow it under Shown range.
- AC-09H204.4: Closing the file or opening another one clears the strip, so no envelope from the old file stays.
- AC-09H204.5: The README desktop screenshot shows the strip under the zoomed chart, and the docs page for opening a recording names the strip.

## Technical Design

Reuse the existing strip component in the File view. Keep the whole-file frame from the unzoomed answer as the strip's only envelope source, with no gaps and a straight warp. A small pure helper turns the file extent and the range on screen into the strip's state. The strip's range request sets the wanted range and asks the backend, as a drag on the chart does. Draw the strip after each chart draw; a new file generation repaints it.

## Testing

Vitest covers the helper and the docs line. The recording-file Playwright spec on WebKit checks the strip, its window after a zoom, and a strip drag.
