# Trigger tests wait for outcomes, and time the collapse in watcher looks

## Summary

A trigger test failed on a loaded macOS runner because it waited only one second for the charger to be seen as gone.
Fifteen tests that only need that outcome shared this one second limit with the timing rule it comes from.
They now wait up to five seconds, as the other waits in the file do.
The three tests that check the one second rule now count the watcher's own looks instead of reading the test's clock.
A starved runner can no longer fail them, and the rule is still checked exactly.

## Requirement

### Steps to reproduce
1. Run the desktop crate's library tests with the e2e feature on a loaded macOS runner.

### Expected
Every trigger test passes on every runner.

### Actual
PR 12 CI run 2 on 2d3c4ca: the plain-contract collapse test failed with "not noticed after 1 s".

## Acceptance Criteria

- AC-N502XX.1: Regression: every trigger test that only needs a collapse, an end of "don't ask again" or a gone charger waits up to 5 s for it; a 1.1 s stall in the watcher's reader no longer fails the plain-contract test, as it did before.
- AC-N502XX.2: The three AC-AXHK2N.9 timing tests assert that the collapse is decided within ceil(spell / 100 ms) + 1 looks of the first low record, the spell being 300 ms rounded up to whole records, that this many looks fit in 1 s at the real check interval, and that the deciding record is 300 ms of device time after the first low one.
- AC-N502XX.3: Those tests log the wall-clock time, keep a 5 s hang guard, and count only the outcome of a run in which a look came later than the stream's stop rule.
- AC-N502XX.4: AXHK2N's Testing section says how the 1 s bound is tested and why the wall clock is not used in CI.
- AC-N502XX.5: The trigger tests pass 50 times in a row under 24 busy loops, and the whole trigger module 50 times under 72.

## Technical Design

### Root cause
`gone_within_a_second` and `disarms_within_a_second` put the 1 s real-time bound of AC-AXHK2N.9 into fifteen outcome-only tests. On a starved runner the watcher's 300 ms spell plus the test thread's polling can take longer than 1 s of wall time.

### Fix
`gone_eventually` and `disarms_eventually` wait 5 s. A `Looks` wrapper counts the watcher's looks and notes the count when the collapse line is written; `decided_within_looks` asserts the rule. No app code changes.

## Testing

The trigger tests in loops under 24 and 72 busy loops; once with a 1.1 s stall injected into the reader; the full gate.
