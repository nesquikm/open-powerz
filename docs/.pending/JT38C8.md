## Meters on the old bootloader (2.1)

Some KM003C meters run bootloader 2.1, older than the 2.5 on current meters. In its bootloader
such a meter shows one vendor interface named after the product and no HID interface. The app
now names that mode instead of calling it unknown: the device list adds "(old bootloader, not
supported yet)" (`deviceOptionLabel`), the details panel shows "Old bootloader" (`modeLabel`),
and Connect is refused before anything is opened (`canConnectTo`). To return to normal, unplug
the meter and plug it back in without holding any button.

The web UI's `DeviceMode` type gains `legacy_bootloader`, the firmware page names the mode
through the same label (`firmwareMeterRows`), and the mock backend has a matching mode in
`MOCK_MODES` for testing.
