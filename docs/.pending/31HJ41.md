## Linux permission message without a source checkout

When Linux refuses access to the meter, the app and the command line now print a one-line
command that writes the udev rule itself (`echo '<rule>' | sudo tee /etc/udev/rules.d/60-powerz.rules`),
then the reload and trigger commands, a replug, and the full web link to the Linux guide. The old
message pointed at a file that exists only in a source checkout, which AppImage users do not have.
The `.deb` package now installs the rule for you, so after installing it only a replug is needed.
The demo backend's copy of the message (`LINUX_PERMISSION_DENIED`) matches.
