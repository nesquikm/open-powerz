## Firmware file inspection (FR V9SK53)

- `firmwareInspect(path)` (new) asks the backend to read a local firmware container file and returns
  its `FirmwareFileInfo`, or rejects with the refusal reason prefixed by the file name.
- `FirmwareFileInfo` (new): `vendor`, `container_version`, `model`, `version`, `date`, `crc` (8
  uppercase hex digits), `size` (bytes, of the decrypted image) and `release_notes_en`.
- The file is never decrypted, and files larger than 8 MiB are refused before they are read.
- `MockBackend` returns synthetic KM003C metadata from `firmwareInspect`.
