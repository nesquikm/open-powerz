## Read the whole session

The chart's time axis counts from the start of the session, not from the meter's own clock.
Short ranges read in seconds, longer ones in minutes and seconds (m:ss), and sessions over an hour in hours, minutes and seconds.
The hover readout and the screen-reader announcements use the same time.

When the meter is unplugged, disconnected or restarts its clock, the session goes on and the chart shows the stretch without data as a shaded band labelled "No data · <length>". No line is drawn across it, in any view, including "Whole session" after a reconnect.

At every zoom each pixel column shows the lowest and highest value it covers, so a single short spike stays visible in "Whole session".

For scripts and other front ends, the backend command `historyGaps` (a list of `HistoryGap` entries, each with a start and an end time) lists the breaks between measuring runs that overlap a time range.
