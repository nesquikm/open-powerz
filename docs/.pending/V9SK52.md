## Device mode and firmware version (FR V9SK52)

- `DeviceMode` (new): `"application" | "bootloader" | "unknown"`. It comes from the USB string of the
  meter's vendor interface (`APP` in application mode).
- `DeviceListing` gains a required `mode: DeviceMode`. A meter in bootloader mode is listed, and its
  picker label from `deviceOptionLabel` ends in "(bootloader mode)".
- `ConnectedInfo` gains `mode`, `bootloader_version` and `warnings`.
- `FirmwareWarningCode` (new): `"too_old"` (below 1.7.0), `"outdated"` (below 2.0.7, the newest version
  known) and `"update_required"` (the meter's HEAD reply says so).
- `Session` keeps the connected meter's details and will not connect to a bootloader-mode meter; the
  backend refuses that connect too.
- `MockBackend` / `MOCK_MODES` add the `bootloader` mode (`?mock=bootloader`), which lists one meter in
  bootloader mode before the demo devices.
