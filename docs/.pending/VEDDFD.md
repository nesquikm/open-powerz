## The session outlives the window's page

The meter session runs in the app's backend, not in the web page that shows it.
When the page reloads (for example with a development reload), the new page asks the backend for the running session
and picks it up instead of starting disconnected: the device, the sample rate, any open recording with its elapsed time,
and the chart and statistics, which refill from the session history: the live 10 s, 1 min and 10 min windows show the minutes before the reload straight away.
From then on only the new page receives the session's events, and Disconnect, Record, Stop, rate changes and Export work as usual.
Closing the window still ends the session.
